
# GoSimplify360 – AWS Cloud Architecture

## Project Overview

GoSimplify360 is a responsive web application built using React, JavaScript, CSS and Vite.

It provides:
- Word Counter
- Age Calculator
- QR Code Generator
- Unit Converter
- Password Generator
- Percentage Calculator

## Project Objective

Design a secure, scalable AWS hosting architecture for GoSimplify360.

## AWS Services

### Amazon S3
Stores production build files generated by Vite.

### Amazon CloudFront
Distributes website content through a content delivery network.

### AWS IAM
Manages access permissions using least privilege.

### Amazon Route 53
Provides DNS management.

### Amazon CloudWatch
Supports monitoring and operational visibility.

## Security

- Apply least-privilege IAM permissions.
- Keep the S3 origin private.
- Use HTTPS.
- Never commit credentials to GitHub.
- Review access and monitoring logs.
